## 1. 기능 개요와 사용자에게 보이는 동작

4인 개인전 생존 게임이다. 6×3 칸의 판 위로 샌드위치가 하늘에서 떨어지고 쌓인다. 플레이어는 이동·점프로 피하고, 쌓인 샌드위치 위로 올라간다. 떨어지는 샌드위치에 깔리면 탈락한다.

- 보통 모드: 60초 타이머. 타이머가 끝나거나, 살아 있는 사람이 1명 이하가 되면 끝난다. 늦게 탈락할수록 순위가 높고, 끝까지 살아남은 사람이 1위다 [판독 6.8].
- 엔드리스 모드(`bq::flag::Check(1)`): 카운트업 타이머, 모두 탈락할 때까지 [판독].
- 칸 하나는 3×3 정사각형이다. 샌드위치도 3×3 크기에 두께 1.0/1.5/2.0/2.5 네 종류다 [데이터].
- 시간이 갈수록 떨어지는 속도·간격·개수가 바뀐다(단계 0~6) [판독 6.2].

## 5. 상태 전이와 전체 수명

### 5.1 샌드위치 하나 [판독]

```
풀(Deactivate) ─StartFall─▶ 낙하(Interpolation 진행, 히트 박스 켬) ─IsEnd─▶ EndFall(착지: 정적 강체·데칼·landing 애니)
      ▲                                                                       │
      └──── nextIndex 가 72개 넘게 앞서면 SetDisableSandwitch(숨김·Deactivate) ◀┘
```

- `StartFall`: 칸·Activate·위치 (칸 x, 칸 높이 + 15, 칸 z)·낙하 보간 시작·`decal` 모션(속도 6.2)·히트 박스·공격 콜백·`SQ_SE_MG0107_SAND_FAL`(2D).
- `EndFall(true)` @0x7100016090: 데칼 그림자, `landing` 모션, 착지 강체(`SetupRigidbodyFalled`), 소리 페이드 [판독, 세부 미판독].
- 오프닝 샌드위치(0번)는 `AddSandwitchOnFieldForOpening`·`SkipFall`로 따로 처리.

### 5.2 플레이어 [판독]

- 시작: `PlayerManager::Start`(흐름 8, 세부 미판독).
- 매 프레임 `Player::OnGameMain @0x710000df04`: 탈락이면 아무것도 안 함. COM이면 `ComAI::OnGameMain`(사람은 오버레이 끔). 위치를 **x ∈ [−8, 8], z ∈ [−4, 4]**로 자른다. 점프 상태가 0→1 이면 발밑 샌드위치 `jump` 모션, 2→0 이면 착지 처리.
- 탈락: 6.5. `dead = 1`, 모델 숨김, 조작 끔, `RankManager::AddDeadTime(현재 시각)`.

### 6.7 COM [판독 `ComAI::*` @0x7100004704~0x7100006c3c, 디스어셈블]

레벨 선택(`ComAI::Setup @0x7100004900`): `GetComLevel` 1 → Normal 표, 2 → Hard, 3 → Master, 그 밖(0) → Easy.

| 레벨 | 보통 모드(t = 남은) | 엔드리스(t = 경과) |

- **Weak** @0x71000050e4: aiState 0 → `SyncRandRange(0,1)`은 **폭 1이라 항상 0, 난수 소비 없음** → 곧바로 2(대기 분기 1~3초는 죽은 코드). 2 → `StartRandomMove`: x ≥ −4.5 면 −1, x ≤ 4.5 면 +1 을 범위로 `SyncRandRangeF(x범위)`·`SyncRandRangeF(z범위)`(z ≤ 3.5 → −1, z ≥ −3.5 → +1) 방향 스틱, `moveTimer = SyncRandRangeF(1,3)`, aiState 4. 4 → 타이머 감소, 점프 중 아니면 `OnRandomJump(25)`: `SyncRandRange(0,25) == 0`이면 점프 버튼(유지 0.2초). 자기 칸에 낙하 중 + cancelTimer < 0 이면 새 무작위 이동(`cancelTimer = SyncRandRangeF(1,2)`). moveTimer < 0 이면 리셋.
- **Normal** @0x7100005f1c: 같은 대기 분기(죽은 코드) → 위치가 판(−8 ≤ x ≤ 8, −4 ≤ z ≤ 4) 안이면 자기 칸 낙하 중이거나 `IsSadwitchOnTopToPosForMaster`면 `StartTargetMove`(옆 칸으로), 아니면 스틱 방향 1.5 앞 점이 샌드위치 AABB 안이면 점프. 판 밖이면 무작위 이동.

- 모든 COM 입력은 `ComActorPad` 오버레이(가상 스틱·버튼)로 들어가 사람과 같은 엔진 이동을 탄다.

## 8. 다른 기능과의 상호작용

- **타이머와 단계**: 단계·속도·COM 전환 모두 UI 타이머 값을 읽는다. 타이머는 시작 텔롭 동안에도 흐른다(6.1).
- **같은 프레임 순서**: 묶음 추가 → 샌드위치 낙하 갱신 → 카메라 → 플레이어(COM). 새 샌드위치는 추가된 프레임에 바로 한 번 떨어진다(같은 OnGameMain 안의 SandwitchManager::Update) [판독].
- **깔림 판정 시점**: 히트 박스 콜백은 엔진 충돌 처리 시점에 불린다 **[미확정]**. 물리 서브스텝(타이밍 0x0F)은 게임 코드 뒤다(SHARED [mgB]).
- **탈락자**: `dead`면 Player::OnGameMain이 일찍 끝나고, 모델은 숨겨진다. 탈락자의 엔티티 위치가 `targetPlayerUnit`의 후보 조건(y ≥ 0)을 만족하는지는 **[미확정]**.
- **난수**: 모두 동기 난수. 사람·COM 행동과 칸 선택이 같은 난수열을 나눠 쓰므로, 사람 입력이 바뀌면 이후 낙하 칸도 바뀐다.

### 9.4 원본과 같게 지킬 것

- 단계 구간은 열린 구간, 경계·범위 밖은 단계 6. 개수 표는 보통/엔드리스 반대 매핑.
- `SyncRandRange(min, max+1)`(양끝 포함), `SyncRandRange(0,1)`은 소비 없음.
- 칸 고르기 순서: `randomUnit` 먼저, 첫 샌드위치면 `targetPlayerUnit` 안에서 `randomUnit`을 한 번 더.
- 낙하는 보간(t²)이고 dt 누적·duration 클램프.
- 칸 높이는 f32 누적, 숨김과 무관하게 줄지 않음.
- 깔림 0.6 기준, 같은 칸 조건.
- 순위 deadTime 은 `trunc(t*100 + 0.01)`.

### 9.6 구현 순서 (권장)

1. `params.ts`·`timer.ts`·단계 함수 → 10절 표와 같은지.
2. 샌드위치 매니저(플레이어 없이) → 같은 시드에서 풀 종류 열·묶음 일정이 파이썬과 같은지.

5. 순위·결과, 엔드리스, 연출.
