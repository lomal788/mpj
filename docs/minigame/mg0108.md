# mg0108 라이트 웨이브 배틀 (Light-Wave Battle)

[데이터] 작성일2026-10-10. 함수 목록·catalog·원본 설정·기존 공용 판독을 조사했다. [catalog][catalog], [TSV][func].
[미확정] **분석 진행: 게임 고유 C 없음. 게임 로직 판독 완료·웹 구현 완료가 아니다.** 원본 실행 확인은 없다. [INDEX][index].
[설계] [판독]은 기존 C 판독 재사용, [판독: 어셈블리]는 기존 명령 판독 재사용, [데이터]는 파일 값, [추정]은 원본 해석, [설계]는 웹 판단, [미확정]은 공백이다. 원본 주소는 모듈과 함께 쓴다. [DESIGN §2·10][design].

## 1. 기능 개요

[데이터] 4인 개인전이다. A로 점프하고 A→A로 엉덩이 찍기를 해 웨이브를 발생시킨다. 웨이브를 점프로 피하면서 마지막까지 살아남는 것이 목표다. [규칙][ruledata] `im_inst_mg0108_rule`, [mgListND][list] `mgList[Name=mg0108].GameRule=VS4`.
[데이터] `inst_mg0108_ctrl00` = A 점프, `inst_mg0108_ctrl01` = A→A 엉덩이 찍기. 이동 스틱 항목은 없다. [조작][controldata].
[데이터] `mgList[Name=mg0108]`는 `Available=1`, `Coin=0`, `Gyro=-1`, `Endless=0`이다. `mgInst[Name=mg0108].ControllerID_0/1/2=0`, `Gyro0_A/1_A/2_A=0`. [목록][list], [설명 설정][instdata].
[설계] 선정 이유와 완화 기준은 [mg0203 부록 D](mg0203.md#부록-d-다섯-게임-후보선정-근거)를 따른다. Gyro=-1·강체 심볼 부재는 모든 숨은 의존이 없다는 증명이 아니다.

## 6. 계산식·의사코드

[미확정] `LightWave::WithinLightWave @0x710000735c`가 높이/거리/진행률을 어떻게 결합하는지, 비교의 `<`/`<=`, 발신자의 자기 파동 면역과 동시 피격 순서를 C 없이 알 수 없다. `Scene::CheckHitLightWave @0x710000f130`, `ProcessHitLightWave @0x71000103d0`, `Player::AddDamage @0x7100007fa8`를 요청한다. [TSV][func].

[설계] 파동 표시 메시는 로직의 파동 위치·수명·소유자·판정 영역 상태를 소비한다. 화면 메시 교차로 승패를 정하지 않는다. 이 상태 필드는 웹 후보 이름이며 원본 구조체 오프셋은 미확정이다. [DESIGN §4·10][design], [TSV][func].

[데이터] NRO 함수 목록의 난수 import thunk: `SyncRandRangeF @0x7100015360`, `SyncRandRange @0x7100015960`. 이것은 main 함수 주소가 아니며 호출 횟수도 아니다. [TSV][func].
[미확정] 준비·본편·CPU·연출별 sync/async 호출자·조건·소비 순서는 C 없이 확정할 수 없다. 난수를0회로 처리하거나 seed당 결과를 만들지 않았다. [TSV][func], [INDEX][index].
