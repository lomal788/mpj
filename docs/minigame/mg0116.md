# mg0116 틀린 쿵쿵 찾기 (Thwomp the Difference)

[데이터] 작성일2026-10-10. 함수 목록·catalog·원본 설정·기존 공용 판독을 조사했다. [catalog][catalog], [TSV][func].
[미확정] **분석 진행: 게임 고유 C 없음. 게임 로직 판독 완료·웹 구현 완료가 아니다.** 원본 실행 확인은 없다. [INDEX][index].
[설계] [판독]은 기존 C 판독 재사용, [판독: 어셈블리]는 기존 명령 판독 재사용, [데이터]는 파일 값, [추정]은 원본 해석, [설계]는 웹 판단, [미확정]은 공백이다. 원본 주소는 모듈과 함께 쓴다. [DESIGN §2·10][design].

## 1. 기능 개요

[데이터] 4인 개인전이다. 쿵쿵 뒤에 숨겨진 그림 네 개 중 다른 그림 하나를 버튼으로 고른다. 빠르게 정답을 맞히면 높은 점수를 얻는다. [규칙][ruledata] `im_inst_mg0116_rule`, [mgListND][list] `mgList[Name=mg0116].GameRule=VS4`.
[데이터] `inst_mg0116_ctrl00` = B/X/Y/A 그림 선택. 버튼과 화면 그림 위치의 정확한 대응은 아직 판독하지 않았다. [조작][controldata].
[데이터] `mgList[Name=mg0116]`는 `Available=1`, `Coin=0`, `Gyro=-1`, `Endless=0`이다. `mgInst[Name=mg0116].ControllerID_0/1/2=0`, `Gyro0_A/1_A/2_A=0`. [목록][list], [설명 설정][instdata].
[설계] 선정 이유와 완화 기준은 [mg0203 부록 D](mg0203.md#부록-d-다섯-게임-후보선정-근거)를 따른다. Gyro=-1·강체 심볼 부재는 모든 숨은 의존이 없다는 증명이 아니다.

## 6. 계산식·의사코드

[미확정] 점수 함수와 config의 시간·배점 인덱스 연결은 C가 없다. 안내문은 빨리 정답이면 고득점만 보장하며 `max(0, 200−t×k)` 같은 식을 만들 근거는 없다. `GameMgr::Update @0x71000074c0`, `Player::SelectConfirmAnswer @0x71000163b0`, `GameMgr::SetPlayerLank @0x7100007e90`를 요청한다. [TSV][func], [규칙][ruledata].

[데이터] `mg0116_DossunTable01_01.csv`의 첫 행은 `[19.5,1,0,1,2.1]`, 이어 `[15.5,0,1,1,2.1]`, `[11.5,1,2,1,2.1]`; 7.5인 두 행의 열2는1·2이다. [표01_01](../../../extracted/bea/mg~mg0116.nx.bea/mg/mg0116/data/mg0116_DossunTable01_01.csv).
[미확정] 위 첫 열이 남은 시간인지, 뒤 열이 쿵쿵 인덱스/방향/속도인지 C 로더가 없으므로 확정하지 않는다. 같은 시간 두 행을 합치거나 정렬하지 않는다. `DossunTableParam::Initialize @0x7100010f70`, `AddTableParam @0x7100011ab0` [TSV][func].

[데이터] NRO 함수 목록의 난수 import thunk: `SyncRandMod @0x710002e150`, `SyncRandModF @0x710002ec20`. 이것은 main 함수 주소가 아니며 호출 횟수도 아니다. [TSV][func].
[미확정] 준비·본편·CPU·연출별 sync/async 호출자·조건·소비 순서는 C 없이 확정할 수 없다. 난수를0회로 처리하거나 seed당 결과를 만들지 않았다. [TSV][func], [INDEX][index].
