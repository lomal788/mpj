## 6. 계산식·의사코드

[판독] config의 FLOAT와 INT는 별도 배열이다. I[0]=3은 **총 라운드 수가 아니라 mode 전환 round**이며 F[7]=.75는 정답자별 점수 표시 간격이다. CSV 전체 행번호로 GetCsvParamF/I를 접근하면 안 된다. 로더 판독은 [20 §6.7][camera20] 재사용, 소비는 mg0116.nro @0x71000074c0 [C][gamec].
[판독] ComParam.Initialize는 CSV의 행0→correctRate int,행1→answerTime float,행2→minTime,행3→maxTime을 각 열0..3 순서로 저장한다. 실제 [com_param](../../../extracted/bea/mg~mg0116.nx.bea/mg/mg0116/data/mg0116_com_param.csv)의 값은 [25,50,75,95]·[4,4,4,4]·[2,1.2,.6,.4]·[2.5,1.5,.8,.5]다. mg0116.nro @0x7100011e80/@0x71000125a0/@0x71000125cc/@0x71000125f8/@0x7100012624 [C][gamec].
[판독] RoundReset은 ComLevel로 min/max를 조회하고 크기순으로 정규화한 뒤 SyncRandModF(max−min) 한 회로 countdown=min+draw를 만든다. +0x168에는 countdown+F[6]를 저장하며 F[6]=1.0이다. 이 초기화는 CPU 전용 if 분기를 두지 않고 Player의 라운드 초기화 경로에 있다. mg0116.nro @0x7100015940 [C][gamec].
[판독] Player.Update는 쿵쿵 높이로 본 그림/정답/오답 수를 기록한다. `seenCount>=3 && seenCorrect` 또는 `wrongCount>=3` 이후에만 countdown을 deltaTime만큼 줄이며, <=0이고 IsCom이면 SelectComAnswer를 호출한다. 사람 입력은 아직 미답이면 TriggerMask 전체를 Reserve에 전달한다. mg0116.nro @0x7100014340 [C][gamec].
[판독] SelectComAnswer는 정답을 뺀 오답 목록을 mode0에서2개,mode1에서3개 만들고 목록 요소마다 한 SyncRandMod로 섞은 뒤 선택 판단용 draw를 한 번 더 소비한다. 총3/4회다. overlay trigger 인자와 modulus 일부가 C에서 소실돼 정답률을 완전히 구현할 수는 없다. mg0116.nro @0x7100014aa0 [C][gamec].
[판독] 점수는 correct list의 rewardIndex에 대응하는 `DAT_710005c290[index]`를 더하고 F[7]=.75 간격으로 표시한다. `200−time*k` 같은 시간 함수가 아니다. actual points와 같은 시각 정답자 목록 순서는 아직 자료/함수 판독 대기다. 전원 최고점<1이면 rank3·WinLose2, 최고 양수 동점은 rank0·WinLose1이다. lower rank 전달 인자 일부는 소실돼 모든 결과를 확정하지 않는다. mg0116.nro @0x71000074c0/@0x7100007e90 [C][gamec].
[판독] SetDossunTablePattern은 디버그 flag 조건에 따라 Params+0x08 값 또는 SyncRandMod 한 회로 pattern을 저장한다. modulus의 정확한 bound와 QuestionType/5 연계는 남는다. mg0116.nro @0x7100006ed0 [C][gamec].

[설계] 단계, 입력 mask, 초기화 draw, 정답 목록 배점을 독립 상태로 유지한다. 미확정 그림 추첨과 점수 테이블을 임의 상수로 메우지 않는다. mg0116.nro @0x71000074c0/@0x7100015470/@0x7100015940 [C][gamec], [DESIGN §10][design].

```text
RoundReset: countdown = min(minTime,maxTime) + SyncRandModF(abs(maxTime-minTime))
Reserve(mask):
    if answered || mask not in allowedExactMasks(mode): return
    answered=true; choice=buttonToPicture(mode,mask)
Confirm: UI.PlayerAnswer(choice,playerOrder)
Award: points += pointTable[correctListIndex]  // pointTable 값 미확정
after round5 award wait: SetPlayerLank(); return finished
```

## 12. 사용자 확인

[설계] 원본 규칙을 기본으로 유지한다. mg0116의 함수 수는 원래800~1,300 기준을 벗어난다. 상한1,646 완화 및 선정 유지/교체는 사용자 확인이 필요한 미승인 추천이다. 다섯 게임이 모든 선정 조건을 충족했다고 선언하지 않는다. [후보 표](mg0203.md#부록-d-다섯-게임-후보선정-근거), [DESIGN §1·10][design].
[설계] §7.1의 그래프/반사/굴절 표현을 근사하려면 사용자 선택이 필요하다. 미승인 상태에서는 원본 그래프 판독 필요로 남긴다. [원본 폴더][archive]의 `Materials[].ShaderAssign.ShaderOptions`, [DESIGN §7][design].
[설계] 판독 후 화면 근사·kit 추출·착수 우선순위·아래 인일 수를 선택할 경우 미승인 추천으로 남긴다. 이번 범위에서 원본 실행·C 추출을 수행하지 않는다. [DESIGN §7·10][design], 부록 C.
