# mg0203 꽈당꽈당 도미노 (Domination)

[데이터] 작성일2026-10-10. 함수 목록·catalog·원본 설정·기존 공용 판독을 조사했다. [catalog][catalog], [TSV][func].
[미확정] **분석 진행: 게임 고유 C 없음. 게임 로직 판독 완료·웹 구현 완료가 아니다.** 원본 실행 확인은 없다. [INDEX][index].
[설계] [판독]은 기존 C 판독 재사용, [판독: 어셈블리]는 기존 명령 판독 재사용, [데이터]는 파일 값, [추정]은 원본 해석, [설계]는 웹 판단, [미확정]은 공백이다. 원본 주소는 모듈과 함께 쓴다. [DESIGN §2·10][design].

## 1. 기능 개요

[데이터] 4인 개인전이다. A를 연타하면 꽈당꽈당이 늘어나며, 10초 동안 가장 긴 도미노를 만든 사람이 이긴다. [규칙][ruledata] `im_inst_mg0203_rule`, [mgListND][list] `mgList[Name=mg0203].GameRule=VS4`.
[데이터] `inst_mg0203_ctrl00` = A 스위치 두드리기. [조작][controldata].
[데이터] `mgList[Name=mg0203]`는 `Available=1`, `Coin=0`, `Gyro=-1`, `Endless=0`이다. `mgInst[Name=mg0203].ControllerID_0/1/2=0`, `Gyro0_A/1_A/2_A=0`. [목록][list], [설명 설정][instdata].
[설계] 선정 이유와 완화 기준은 [mg0203 부록 D](mg0203.md#부록-d-다섯-게임-후보선정-근거)를 따른다. Gyro=-1·강체 심볼 부재는 모든 숨은 의존이 없다는 증명이 아니다.

## 5. 상태·수명

[판독] 공용 main @0x71002e0500/@0x71002e0844의 준비→오프닝/스킵→시작→본편→종료→결과→퇴장 흐름은 [틀 §5·12.12][frame] 재사용이다.
[설계] mg0203는 MgGame 훅을 구현하고 게임 상태를 소유한다. 생성/정리·오프닝·본편·결과를 틀 단계에 연결한다. Work·저장·복귀는 app/minigame/frame 책임이다. [DESIGN §10.5][design], [틀 §12.12.1·12.12.4][frame].
[미확정] 고유 상태 번호·초기화·훅 반환값·결과 등록·엔티티/풀 정리 순서는 미판독이다. §3 심볼 목록을 실행 순서로 해석하지 않는다. [TSV][func], 부록 C.

## 6. 계산식·의사코드

[미확정] `A trigger → 카운트 +1`을 원본 의사코드로 확정할 C가 없다. `Players::OnHit @0x710000cde0`, `Battan::UpdateCount @0x7100006e40`, `Stage::SwitchOn @0x71000179c0`가 각각 입력·모션·도미노 생성에 어떤 순서로 연결되는지 판독 필요다. [TSV][func].

[데이터] 안내문 승부시간은 10초다. [규칙][ruledata] `im_inst_mg0203_rule`.
[설계] 600개의 고정 스텝은 10초에 대응하는 시험용 시간 구간이다. 수락하는 첫/마지막 프레임은 C 확보 뒤 고정한다. 공용 안전 종료 180초를 10초 게임 타이머로 바꾸어 쓰지 않는다. [틀 §6.4·12.12.6][frame].

[데이터] NRO 함수 목록의 난수 import thunk: `RandRange @0x7100019790`(async), `SyncRandRange @0x7100019cd0`, `SyncRandRangeF @0x7100019ce0`. 이것은 main 함수 주소가 아니며 호출 횟수도 아니다. [TSV][func].
[미확정] 준비·본편·CPU·연출별 sync/async 호출자·조건·소비 순서는 C 없이 확정할 수 없다. 난수를0회로 처리하거나 seed당 결과를 만들지 않았다. [TSV][func], [INDEX][index].

[미확정] 선정 5종 모두 게임 고유 C를 찾지 못했다. C 없는 함수의 호출 순서·상수·분기·필드·난수 소비는 판독하거나 추출하지 않는다. 이번 산출물은 데이터 계약과 판독 요청을 담는 분석 진행 문서이며, 게임 로직 판독 완료가 아니다. [INDEX.tsv](../../../analysis/decomp/INDEX.tsv).
