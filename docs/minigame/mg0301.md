# mg0301 클러셔 로봇을 피해 도망쳐라 (Broozer Bash)

[판독] 2026-10-10. **게임 고유 본문·자료 분석이며 원본 실행 확인은 없다.** 최초 대조 때 mg0301 C가 없었으나, 후속 사용자 승인에 따라 [추출 가이드][guide]의 소형 NRO 전체 추출을 수행했다. [mg0301.nro.c][native]에 1,677개 함수가 출력되었고 [INDEX][index]에 같은 수의 행을 append했다. 기존 102주소 본문 검토에 이어 **미확정 15항목(U01~U15) 전체의 C 본체·수식·ABI 정밀 분석을 완료**하여 본 문서에 전면 반영했다. 기존 프로젝트·C·에셋은 보존했다. 새 SASS 판독·원본 실행·웹 구현은 하지 않았다.

[설계] `[판독]`은 기존 공용 판독의 재사용, `[데이터]`는 원본 설정·파일 파싱·심볼 존재, `[추정]`은 미검증 해석, `[설계]`는 웹 제안, `[미확정]`은 구현을 막는 근거 공백이다. 함수 주소는 모듈과 함께 쓴다. 주소 없는 에셋은 파일 경로와 필드·행·트랙을 인용하며 주소를 만들지 않는다. [DESIGN §2·3·10][design].

## 6. 식·조건·의사코드

### 6.1 시간·팀 결과

[판독] 다음은 유효 1VS3 참가자라는 전제에서 C의 분기를 줄인 것이다. `Run`과 `End`가 생존자를 각각 검사함을 보존한다. mg0301.nro `@0x710002f3c0/@0x710002f4b0/@0x7100030510` [native].

```text
Run():
  if timer.IsEnd(): return done
  for p in escapePlayers:
    if !p.actor.IsBeated(): return running
  return done
End():
  survivors = escapePlayers.filter(p => !p.actor.IsBeated())
  if survivors.empty: notify Annihilation(machinePlayer)
  else: notify Survivors(survivors)
  for p in escapePlayers: p.winLose = survivors.empty ? 0 : 1
  machinePlayer.winLose = survivors.empty ? 1 : 0
  timer.Stop()
```

[판독] 경계 틱 승패 판정: `Mainpart::Run`에서 timer 종료 시 즉시 Run을 끝내고 `Mainpart::End`로 진입한다. `End`는 잔여 시간에 관계없이 현재 `escapePlayers` 목록에서 `!IsBeated()`인 생존자를 필터링한다. 생존자가 0명이면 Annihilation 통지와 함께 전원 도망팀 winLose=0, 로봇 winLose=1을 기록하며, 1명 이상이면 Survivors 통지와 함께 도망팀 winLose=1(이미 맞은 탈락자 포함 전원 승리), 로봇 winLose=0을 기록한다. 따라서 마지막 피격과 시간 초과가 같은 프레임에 발생하더라도 `End` 시점에 마지막 플레이어가 이미 피격(`IsBeated`)되어 있다면 로봇 승리로 확정되며 동점 분기는 없다. mg0301.nro `@0x710002f3c0/@0x710002f4b0/@0x7100030510` [native].

### 6.2 조종·이동·공격

[판독] `F`는 f32 반올림 표시다. Pad +40 hold를 읽으며 trigger 조건은 아니다. 초기 `elapsed=limit=F(.2)`라 아무 입력이 없으면 전진하지 않는다. +80의 1.6을 가속도나 공격 주기로 쓰는 근거는 없다. mg0301.nro `@0x7100031c50/@0x71000320a0` [native].

```text
if hold & 1: elapsed = F(0)
else: elapsed = min(F(elapsed + dt), limit)
left  = (hold & 0x50) != 0
right = (hold & 0xa0) != 0
if left && right: flags &= ~6
else if left: flags |= 2
else if right: flags |= 4
if elapsed < limit: flags |= 1
```

[판독] Machine의 event0: bit2이면 양의 Y축 회전, bit4이면 음의 Y축 회전; 회전 후 로컬 +Z를 새 회전으로 변환하여 `F(2.7*dt)`만큼 이동한다. 회전은 quaternion 반각 `F(F(2.2*dt)*.5)`의 sin/cos 테일러 다항식 근사(`SinCoefficients` 5차/7차, `CosCoefficients` 짝수차, 2pi 랩어라운드 및 [-pi/2, pi/2] 범위 축소)로 `q_delta = (0, sin, 0, cos)`를 구하고 기존 회전에 곱한다. 새 flag와 이전 flag의 low4bit가 다를 때 parts 상태를 알리고 low4bit를 지운다. mg0301.nro `@0x710004de20` [native].

[판독] Body/벨트/핸들/탑승자 상태는 flag 0=idle,1=move_f,2=turn_l,3=move_l,4=turn_r,5=move_r에 대응한다. Body만 전진 시 `$body_attack`, 승리 시 `$body_battle_cry`로 별도 분기한다. 장갑의 `active=flags&1`은 애니 프레임과 독립적이다. mg0301.nro `@0x710004bed0/@0x710004ee10/@0x710004fd50/@0x7100051b40/@0x7100053850` [native].

### 6.4 CPU

[판독] 도망 CPU는 피격되면 Run 종료. 잠재장으로 약 1초 앞까지 현재 actor speed를 사용해 이동을 예측한다. force 활성과 참가 인덱스 mask를 검사한다. state1에서 예측 길이≤.5면 state2, state2에서 길이≥2이고 진행 보간값이 유효하면 SleepTime을 뽑아 state3, sleep≤0이면 state1이다. state1의 현재 force XZ를 스틱(X,−Z)로 바꾸고 정규화한 뒤 `stick += (target−stick)*F(dt*column0)`; 다른 상태는 스틱0이다. 포텐셜 반발력 합산 벡터가 스틱 목표값으로 직접 변환된다. mg0301.nro `@0x7100003830/@0x7100005b18/@0x710004a160` [native].

[판독] `elapsed=F(elapsed+dt)`, `advance=max(0,F(F(elapsed−col1)/F(col2−col1)))`; 분모0이면0이며 **상한1 clamp가 없다**. SleepTime은 col3→5, col4→6 두 끝점을 advance로 보간하고 정렬한 후 `lo+SyncRandModF(hi−lo)`다. 함수의 optional 유효 비트는 별도다. mg0301.nro `@0x7100003dcc/@0x7100004008` [native]·[cpuactor].

[판독] 로봇 CPU는 맞은 대상을 제외한다. 첫 시도는 `SyncRandMod(후보수)`로 대상을 고르고 다음 시도들은 가장 가까운 대상을 찾는다(동거리에서 기존 앞선 후보 유지). `AccuracyRad`는 `SyncRandMod(2)`로 부호를 뽑고 `col3~4` 범위에서 `SyncRandModF(hi-lo)`로 오차 크기를 결정한다. 목표 방향에 오차각을 더한 방향으로 회전하고 대기한 뒤 추적한다. `Is_Turn_Enable`의 `on` 또는 전방 probe 충돌이면 초기 회전 단계로 간다. 추적 중 각 오차가 `abs(error)<=.05` rad이면 직진(`0x01`), 오차가 클 때 0x11/0x21(전진+회전) 또는 0x10/0x20(단독 회전)을 주입한다. mg0301.nro `@0x7100004230/@0x7100005480/@0x7100005588` [native].

### 6.6 f32와 재구현 계산

[설계] `F(a+F(b*dt))`와 `F(a+b*dt)`를 구분한다. 입력 유지 비교는 갱신 후 `<limit`, CPU sleep은 감소 후 비교다. 고정 dt는 웹의 `F(1/60)`이며 원본 공용 GetDeltaTime 계약과 구분한다. mg0301.nro `@0x71000320a0/@0x7100003830` [native]·[design].

[데이터: 재구현 계산] `F(1/60)=0.01666666753590107`, `F(F(2.7)*dt)=0.04500000178813934`, `F(F(2.2)*dt)=0.03666666895151138`. CSV→f32, 곱→f32로 계산한 단일 tick 기대값이다. quaternion의 근사 sin/cos, 충돌 보정 후 위치까지 검증한 값은 아니다. mg0301.nro `@0x710004de20` [native]·[config].

[데이터: 재구현 계산] UITimer의 실제 감소식은 `remain = remain - dt`이며, 30.0초에서 고정 dt 1/60을 1,800회 감산하면 정확히 0 이하에 도달하여 타이머 상태 3(Timeout)으로 종료된다. .2 유지값에 dt를 누적하는 실제 입력 비교식은 무입력 12번째 갱신에 limit로 clamp되어 전진이 꺼진다. mg0301.nro `@0x71000320a0/@0x71000303e0` [native].

```text
// [설계] 확정된 전역 5단계 순서(U10)에 기반한 웹 디스패처 의사코드.
if !FrameGate.canStep(frame): return
pads = FrameGate.inputsFor(frame)
stepGame(pads, F(1/60), injectedRng)
publishStateAndEvents()
render(snapshot)  // 게임 상태와 sync RNG를 변경하지 않음
```
