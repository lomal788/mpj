## 1. 기능 개요와 사용자에게 보이는 동작

4인 화면 분할(SplitScreen) 스노보드 레이스. 로젤리나(NPC)가 앞에서 길을 만들며 달리고, 플레이어 4명이 뒤따라 코스를 미끄러져 골까지 간다.

- 조작: Joy-Con R **세로 쥐기**, 좌우로 기울여 코너링한다(`inst_mg0906_ctrl00` "스노보드를 기울여서 코너링").
  - 점프대에서 타이밍 맞춰 휘두르면 더 멀리 뛴다(`im_inst_mg0906_rule`).
- 코스는 두 구간이다. 눈 코스(거리 0~약 2410 m) 다음 우주 코스(약 2411~5310 m)이고, 우주 코스가 더 빠르다(최고 120 → 150 km/h).
- 코스 위 요소
  - 가속 존(대시 패널)
  - 큰 가속 존(거리 2720~2920)
  - 가속 아이템(로젤리나가 뿌린다)
  - 바위
  - 점프대(중·대)
  - 흙(감속)
  - 벽
- 플레이어끼리 부딪히면 튕긴다.
- **어드밴티지 플레이어는 스타트 직전에 가속 아이템을 받는다**(`im_inst_mg0906_adv`, ParamMgr+0x50).
- 3명이 골인하면 끝난다. GameJudgeType 1이면 첫 골인에서 끝난다(6.9). 같은 프레임 골인은 난수로 순서를 정한다.

| 근거 | 내용 |
|---|---|
| [데이터] `mgListND.json` | `"Name":"mg0906","DebugTitleName":"ロゼッタチェイス","GameRule":"Chara","Tired":0,"Gyro":0,"CallInst":1` |
| [데이터] `mgSetting` | `OpeningSkip 0`, `GameEndTimerPos "CC"`, `GameEndTime 300`, `StatusOutTiming "FadeOut"`, `EndSeqWaitTime 0` |

| [데이터] `pcMotionArcList.json` | `{"name":"mg0906","keyList":["sbr"]}` → `chara/pcMot_sbr` |

`mg0906::Timer`는 **문자열 키 타이머 묶음**이다. 키로는 "Accel", "ReturnMoveSpeed", "Turn", "QuickTurnEnableInput", "AccelDisableInput", "Spinning", "HitWall", "GroundOffset", "UpdateRank" 등이 보인다 [판독: 키 문자열].

### 3.2 준비 [판독]

`SyncedSetupGame`이 다음 순서로 만든다.

1. 장면 엔티티와 `ParamMgr::SetupGame(Params*)`
   - 바위·점프대·가속 데이터를 JSON에서 읽는다.
   - 어드밴티지 플레이어 순서를 ParamMgr+0x50에 넣는다(없으면 −1).
2. 시작 텔롭
3. 오프닝 자리 모델(`mg0906_op02_pos_pc`)
4. 매니저 SetupGame: AccelItem → AccelZone → Camera → Collision → Course → CourseObject → JumpBoard → **PlayerMgr**
5. 카메라 초기화용 `PlayerMgr::UpdateMain` + `CameraMgr::UpdateMain` 4회
6. UIMgr

### 3.4 본편 한 프레임 `Scene::OnGameMain` [판독]

`OnGameMain`은 장면 흐름(MinigameFlow 파이버)이 매 프레임 부른다. mg0118처럼 따로 파이버를 만들지 않는다 [판독: OnGameMain 본문].

```
TimerMgr.Update()
PlayerMgr.UpdateMain()                       // 6.1: Player 0..3 갱신 → 반투명·표시 → 순위 → 골 연출 시작
Rosetta.UpdateMain(선두 거리, 꼴찌 거리, 선두 속도)
AccelItemMgr.UpdateMain(거리[4]); AccelZoneMgr.UpdateMain(로젤리나 거리, 거리[4])
Bgm.UpdateMain(선두 거리)
JumpBoardMgr / CourseMgr / CourseEnvironment / CourseObjectMgr .UpdateMain(…)
CameraMgr.UpdateMain(i, 거리_i, 상대위치_i, …)  i = 0..3   // 화면 4분할
if (Timer "UpdateRank" 끝) { UIMgr.SetRank(순위); 다시 시작(0.5 s) }
return PlayerMgr.IsFinishedGame()
```

### 6.3 속도 PlayerSpeed::UpdateMoveSpeed [판독 @0x710002eb00, GetMaxMoveSpeed @0x710002e9a4(디스어셈블)]

### 6.4 선회·이동 [판독 요약 `Player::UpdateTurn @0x710001c43c`(7,272 B), `UpdateMoveAccel @0x710001e0a8`, `UpdateTransform @0x710001bd1c`]

- `UpdateTurn`
  - `UpdateTurnSpeed(입력)` 뒤 진행 방향(heading, +0x5E0 방향)을 `turnSpeed·dt`(도/s로 보임 [추정])만큼 코스 위쪽 벡터 축으로 돌린다.
  - 코스 진행 방향(+0x640) 기준으로 각도를 제한하고 보정한다. 디컴파일에 sin/cos 다항식·atan·slerp(0.9/0.1 가중)가 펼쳐져 있다.
  - 퀵턴: Joy-Con 각도 ≥ quick_turn_start_joy_con_angle(45°)일 때 25°. 입력 가능 0.5 s("QuickTurnEnableInput" 타이머는 점프 입력이 연다).
  - **세부 식은 [미확정]**이다(웹 첫 구현은 heading 각을 turnSpeed로 적분하고, 코스 방향과의 차를 ±90°로 자르는 근사를 쓰고 근사 절에 적는다).
- `UpdateMoveAccel`
  - 진행 방향 `+0x640 = normalize(Course(d + speed·dt) − Course(d))`
  - 이동 벡터 `+0x5E0 = normalize(+0x5E0)·speed·dt`
- 위치는 이동 벡터·튕김 벡터를 더한 3D 점이다. 그 뒤 6.6이 코스 바닥에 붙이고 거리를 다시 구한다.

### 6.6 코스 바닥·거리 재투영 [판독 `Player::UpdateHitCourse @0x710001e510`, `PlayerRay::CastRayToCourse @0x7100023690`]

- `nn::bezel::PhysicsModule::CastRayAll`로 위에서 아래로 쏜다. 태그 "Course"(바닥), "GoalArea", "JumpBoard", "Dirt" 엔티티를 가른다. 기하는 nbmap이 참조하는 `.apx` 삼각 메시다(7.2).
- **거리 재투영**은 3단 탐색이다. 위치와 `CourseLocator.GetPosition(d)`의 거리가 가장 작은 d를 찾는다.
  1. 0.5 간격으로 (이전 d 주변 ~ d + 5)
  2. ±0.5를 0.1 간격으로
  3. ±0.1을 0.01 간격으로
  - 끝 조건이 갱신된 최적값을 따라 늘어나는 원본 특이점이 있다. 그대로 옮긴다.
- d가 `CourseLocator+0x18`(눈→우주)을 넘는 프레임에 "GroundOffset" 타이머 0.5 s를 시작한다.
- d ≥ `+0x1C`(끝)이면 상태 비트 4(골)를 켠다.
- `+0x610 = 위치 − Course(d)`(코스 기준 상대 위치)에 점프 벡터를 더한다.

### 6.8 CPU [판독 `Com::UpdateInput @0x710001695c`(일부 디스어셈블)]

- 판단은 `com.<레벨>.action_interval_time_sec`(0.1 s) 타이머마다 한다.
- 점프대 위에 올라선 첫 프레임에 `SyncRandRange(0, 100)` < `jump_succeed_probability`(25/50/75/100)이면 점프 콜백을 부른다(성공 점프).
- 조향
  - `CollisionMgr::GetComNearestTargetParam(거리, 앞 범위, 옆 범위)`가 가까운 목표(가속 존·아이템 등)를 찾는다. 목표 오프셋과 내 오프셋 차가 1 m를 넘으면 `inputX = clamp((목표 − 나)/5, −1, 1)`.
  - 아니면 벽 탐색(`GetNearestWallParam`, `com.turns` 구간·`check_hit_wall_distance_range`)으로 입력을 정한다.
- 세부(목표 우선순위, `amplitude_percent` 흔들림)는 **[미확정]**이다.

### 6.9 순위·종료 [판독 `PlayerMgr::UpdateRank @0x710002bb10`, `ProcessGoal @0x710002be50`, `IsFinishedGame @0x710002c0c0`(디스어셈블), `OnGameEnd @0x710002a89c`]

## 8. 다른 기능과의 상호작용

- **입력 차단**은 다음 경우다.
  - state 1
  - 스핀·충돌 튕김 중
  - 벽 자동 모드
  - "AccelDisableInput"(가속 직후 0.2 s)
  - state 4
  - 큰 가속 존 구간(accelType 3)
- **같은 프레임 순서**는 다음과 같다.
  - Player 0→3
  - 로젤리나·오브젝트 매니저
  - 카메라 4개
  - UI 순위(0.5 s 간격)
  - 종료 판정
- 골 순위는 PlayerMgr 갱신 끝에서 정한다.
- **코스 전환**: 거리 > +0x18이면 모든 거리 의존 파라미터가 우주 값으로 바뀐다(속도 상한 33.3 → 41.7 m/s 등). 바닥 오프셋 보간 0.5 s가 붙는다.
- **어드밴티지**: 오프닝에서 대상 플레이어만 가속 아이템을 받는다(StartAccel 4, 145 km/h) [추정].
